## Computer Vision Internship Assessment – OpenCV Projects

This repository contains solutions for all three tasks assigned as part of the Computer Vision Internship Assessment. The goal of these tasks is to demonstrate foundational OpenCV and Python skills, along with the ability to write clean code and technical documentation.


## Contents
Task 1: Basic Image Manipulation
Task 2: Mini Project – Color Detector
Task 3: 1-Page Technical Summary Report (PDF)

### Prerequisites
- Python 3.8-3.10
- OpenCV (`pip install opencv-python`)
- Pandas version: 2.2.3
NumPy version: 2.0.2
Matplotlib version: 3.9.4
OpenCV version: 4.11.0

python 3.9.13

## Task 1 – Basic Image Manipulation (Task1Image Manipulation.ipynb)
Objective:
Apply basic image processing techniques on a chosen image.

Operations Performed:
  1. Convert image to Grayscale
  2. Apply Gaussian Blur
  3.Detect edges using Canny Edge Detector (NOTE : THERE IS THE TRACKBAR TO ADJUST MAXIMUM AND MINIMUM THRESHOLD OF THE SELECTED IMAGES, 
    YOU CAN ADJUST IT ACCORDING TO YOUR IMAGE)

Output:
Processed images are saved in the output_task1/ folder:
grayscale.jpg
blurred.jpg
edges.jpg

Task 2 – Color Detector
Objective:
         Create a webcam-based tool to detect and identify BGR color values on mouse clicks.

Features:
    * Click anywhere on the webcam frame to get:
      BGR color values
      Closest color name from a predefined dictionary (e.g., Red, Green, Blue)
      Displays detected color name and a sample rectangle

Run : Color detector.ipynb
💡 Ensure your webcam is connected and accessible.
